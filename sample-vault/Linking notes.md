# Linking notes

Links are written as `[[Note title]]`. You can link to a heading with `[[Note title#Heading]]` and change the visible text with `[[Note title|text]]`.

Every link creates a backlink: open the **Backlinks** tab on [[Welcome]] to see this note listed there.

Unlinked mentions are places where a note's title appears as plain text. The Backlinks tab lists them and can turn each one into a link, and the Auto-link tab does the same for the note you're editing.

Renaming a note updates every link that points to it. See also: Weekly review.
